# 10 个情绪与注意动作

每个目录保存 512 × 512 RGBA 无损 WebP，速度为 24 帧/秒。`trajectories.json` 的 `intervals` 是播放帧数。各目录从 `00000.webp` 起连续编号，多存一张和下一个站立起点完全一致的终帧，打包时只播放前 N 张。

| 片段 | 动作设计 | 触发 |
| --- | --- | --- |
| excited | 短蓄力、连续两次身体回弹，尾尖落后于尾根 | 兴奋意图、活跃时自主行为 |
| cuddle | 脸颊向一侧靠过去，轻闭双眼，再缓缓回正 | 双击抱抱、聊天抱抱 |
| sleepy | 眼睑下垂，点头，再短暂抬头 | 困倦意图、休息自主行为 |
| shy | 先低头避开视线，再回看一次 | 害羞意图 |
| startled | 突然向后上方收头，睁眼定住，尾巴随后恢复 | 惊讶意图 |
| pet_head | 以两次不同强度的摸头带动耳、颈和眼睑回应 | 短抚头部 |
| request_pet | 伸颈把头送向手，稍停，又探出一次 | 安静时段外低频互动请求 |
| seek | 先看近侧，再寻找另一个方向和高度 | 空闲寻找 |
| call | 先竖耳，快速回头盯住呼唤方向，随后摇尾 | 首页呼唤 |
| follow | 随示例指尖先向左下、再向右上、最后回看 | 录制指向用于示例与自主注意；实际持续短抚由实时 XY 指向驱动 |

`emotions.py` 依赖相邻目录的 `perform/performance.py`、原项目的 `art/puppet/expressions/head-expressions.png` 与原站姿画稿。张望、呼唤和跟随复用单纹理头颈曲面，以角度记录水平转头，并在原稿位置配准眼睑及口型。需要 Python、NumPy、SciPy、Pillow 及 OpenCV。从仓库根目录运行 `python art/live2d/review2/emotions/emotions.py` 可重新生成，随后运行 `python art/live2d/review2/emotions/verify.py`。设置 `CUTEDOG_EMOTION_OUT` 可以指定同一套生成与验证的输出目录。验收包含全帧解码、实际尺寸与透明通道、固定足尖像素、每段入口出口逐像素相等、姿态变化数量和放大抽检。

`follow` 的 `targetX/targetY` 给出示例轨迹的归一化坐标。实际连续短抚使用带自然呼吸的站姿作为底图。手机读取用户的手指位置，按 HeadTail 同一组眼、鼻、耳深度与颈根，在 32×32 的投影网格上做偏航和俯仰。顶点投影支持两种朝向，肩部和脚掌固定。此时录制的示例轨迹停用，手指松开后平滑回正。真实触控手感与帧率需在手机上核验。
