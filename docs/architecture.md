# 架构与系统兼容性

## 技术选择

CuteDog 采用 Kotlin + Jetpack Compose/Material3。Android 原生服务、AlarmManager 和 NotificationManager 负责系统能力，SQLiteOpenHelper + WAL 保存事项、聊天、显式记忆和短句历史。直接使用 SQLite 是为了控制本版迁移及依赖体积；数据库操作在 IO 线程执行，UI 不通过网络请求驱动渲染时钟。

桌宠悬浮层使用 `FrameClipPlayer`，通过 Canvas 播放 512 × 512 的整犬透明帧。Cubism 制作与烘焙发生在开发阶段，设备按清单解码并缓存即将播放的帧。主界面提供设置、待办和聊天入口。

## 模块边界

```text
MainActivity / ui          页面、导航、编辑草稿、显式权限与联网同意
 ├─ data                   事项与本机 SQLite
 ├─ reminder               日期计算、自然时间草稿、闹钟与通知动作
 ├─ daily                  原创短句选择、历史收藏、每日通知
 ├─ chat                   HTTPS 模型、上下文、记忆、Keystore 密钥
 ├─ voice                  按住录音、豆包实时语音与搜索、流式播放
 └─ pet                    行为状态机、纹理渲染、触摸、悬浮服务
```

网络运行在 `Dispatchers.IO`；请求可取消，有连接/读取/总超时与输出上限。UI关停不会取消系统已注册的提醒。闹钟收到后访问持久化事项，通过投递记录抑制重复，再发送通知；正在运行的桌宠可收到应用内事件，展示有限时长气泡。提醒不会为了展示气泡偷偷从后台新建桌宠服务。

状态机区分基础姿态、移动速度、交互目标与安静/活跃倾向。移动减速后进入互动；睡眠先坐下、趴下，唤醒后伸展；跳跃使用连续高度和着地状态。选择加入上下文与近期冷却，避免纯固定轮播。状态名不代表该动作拥有独立的高质量动画素材，详见验收清单。

## 数据与隐私

| 数据 | 保存位置与控制 |
|---|---|
| 提醒 | 应用私有 SQLite；标题、详情、绝对时间、重复时区、月度锚点、提前量、完成状态、稍后时间 |
| 聊天 | 独立 SQLite 保存角色、正文、时间、语音来源和回复关联。桌面小窗与陪伴页共享记录，支持逐条删除或清空 |
| 麦克风 | 用户同意后，前台按住时采集并实时发送给豆包，最多 30 秒。手机只在内存中暂存录音 |
| 语音对话 | 豆包 Seeduplex 生成听写、回答和语音，配置搜索 Key 后可联网查询。近期对话上下文随请求发送 |
| 长期记忆 | 用户手动管理，默认不发送；启用后随请求发送，支持编辑/删除/清空/导出 |
| API Key | Android Keystore AES-GCM 密钥加密后存入私有偏好设置；不写日志或仓库 |
| 设置与短句 | 本机偏好设置及 SQLite；无远程账户同步 |

禁用系统备份，防止密文密钥与设备 Keystore 分离恢复；卸载会丢失本地数据。没有通讯录、位置、无障碍、截屏或使用情况统计权限。联网聊天的对方服务可以保留收到的数据，本地清空不会远程撤销。

## Android 版本与权限矩阵

| 能力 | API26–30 | API31–32 | API33 | API34–35 |
|---|---|---|---|---|
| 悬浮桌宠 | 用户授权 TYPE_APPLICATION_OVERLAY；常驻前台通知 | 同左 | 同左，通知需另授权 | specialUse 前台服务类型及权限；前台用户主动启动 |
| 精确提醒 | AlarmManager setExactAndAllowWhileIdle | 检查精确闹钟授权 | 同左 | 新安装默认可能拒绝；每次调度检查并降级 |
| 通知 | 用户可关闭频道 | 同左 | POST_NOTIFICATIONS 运行时权限 | 同左 |
| 设备重启 | RECEIVE_BOOT_COMPLETED 恢复闹钟 | 同左 | 同左 | 同左；桌宠只提供通知恢复入口 |
| 聊天 | HTTPS + Android Keystore | 同左 | 同左 | 同左 |

目标 SDK35；API36及以后的行为未在本轮验证。Google Play 对 specialUse 有单独审核，侧载测试 APK 不代表商店审核通过。

## 空间、功耗与限制

桌宠平时只占用狗身的小悬浮窗。双击打开互动菜单期间，点菜单以外的区域会收起菜单。用户可在「活动范围」画出一个活动区和最多八个避让区，桌宠移动时按这个布局避开已标记的位置。系统栏自动参与边界计算，旋转后会重新计算位置。[活动范围编辑器](../app/src/main/java/com/cutedog/app/ui/PetRegionEditor.kt)

活动渲染约30fps；睡眠约12fps；省电/减少动态约10fps；息屏/隐藏停止动画与移动循环。位图缓存、复用 Rect/Paint，避免每帧大型分配。尚未做长时间电池、GPU与内存泄漏测量，不能保证商用品质续航。

强制停止应用、厂商极端省电、禁止通知、设备关机均可能阻断提醒。已拒绝精确闹钟的非精确路径可能延迟。重复事项采用创建时区计算日历重复，避免夏令时及月末31日漂移；UI显示当前设备时区，跨时区使用应复核。具体通知完成与稍后语义见 reminders.md。
