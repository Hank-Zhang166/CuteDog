# 每日一句：内容与调度说明

`app/src/main/assets/quotes.txt` 是本项目为 CuteDog 编写的 372 条中文短句，每行一条，采用 UTF-8。全部为本次研发独立创作，未批量摘抄作品、歌词或名人语录，也未作诗人归属。文字经过主题与措辞审读，覆盖晨间、休息与情绪、四季、学习工作、人际关系、生活细节、纪念日、宠物陪伴和夜间。没有使用模板组合生成短句。

这些文字表达一般性的陪伴与善意，不作医疗承诺、不制造离开应用的愧疚，也鼓励保持现实中的社交与求助渠道。其可编辑源文件就是 `quotes.txt`，随项目源码一同提供。生成式辅助创作在不同法域的独占版权状态可能不同；本项目不声称拥有第三方经典作品的权利。

## 稳定性与去重

- Quote ID 为资源文件中从 0 开始的行号。发布后请保留已发布行的顺序；新增内容追加到末尾，避免改变历史收藏的含义。
- 选择索引为 `(year × 37 + dayOfYear − 1) mod quoteCount`。一年有 365 或 366 天，条目数不少于 366，因此同一年内没有重复。不同年份旋转起点。
- 问候按设备本地日期计算，不需要上传地点、日历或其他个人资料。生日/节日风格短句包含在库中，但本版本不采集生日，也未声称按真实节日自动匹配。
- 当前日期进入应用或被通知展示时，SQLite 保存查看历史；收藏按稳定的 Quote ID 保存，可以再次取消。历史/收藏均在本地。
- 单元测试检查实际打包源文件的条数、空行、规范化后的重复、适合小气泡的长度；另测试平年/闰年分配、静音跨午夜、时区和夏令时规则。

## 后台行为与限制

默认设置为每天 09:00、安静时段 22:00–08:00，可以关闭或修改。通知遵守 Android 通知授权和频道开关。使用低重要性、无声、无振动的通知频道；问候不启动悬浮服务、不弹出后台 Activity，也不监听敏感屏幕内容。

问候不是紧急提醒，采用 `AlarmManager.RTC` 非唤醒、非精确的一次性闹钟，下次触发后重新计算日程。设备休眠、Doze、电池策略可能延后展示；错过的旧日期不补发成批通知，下一次打开应用仍可查看当天短句。设置的问候时刻落在安静时段时顺延到安静时段结束；两端时刻相同表示不设安静时段。

成功调用通知发布后才在本地记录已主动问候的日期，每天最多发布一次。调用 `today()` 只记录查看历史，不把通知标记为已发送。用户撤销通知权限时不记录发送，应用内容仍可用。系统强行停止应用后，Android 会取消后续调度，需再次打开应用恢复。系统重启、时间或时区变动的恢复由主应用的 RestoreReceiver 重新调用 `DailyScheduler.schedule()`。

Android 单元测试不能证明厂商后台策略下的交付时刻。设备上的通知权限撤销、跨午夜、重启和 Doze 验证须在测试报告中独立列出，不能以纯函数测试替代。
