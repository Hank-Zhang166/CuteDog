# 桌宠互动与动作预览

## 点击小狗与待办

在「小狗」页开启悬浮窗权限并召唤桌宠。轻点头部，小萨会享受摸头、蹭一蹭或歪头。点腿或爪子，它会抬爪、舔爪或伸展。点尾巴会摇尾。点躯干使用「互动手势」里的设置。命中区域跟随每一帧的姿势和朝向，避开透明处和嘴边的球、零食与勺子。

在小狗身上同一位置双击打开互动菜单，可以选投球、喂食、摸摸、呼唤或休息等。点「聊聊天」在桌面上打开聊天小窗，点「收起聊天」回到原先的界面。保持按住后再移动即可拖动桌宠。锁定位置时仍可轻抚、双击和使用菜单。屏幕阅读器通过「打开互动菜单」操作进入。

在菜单中按住麦克风说话，松手发送，录制中把手指移出按钮会取消。首次使用时由 Android 询问麦克风权限，允许后需重新按住。点菜单外可以收起菜单，正在进行的语音轮次会停止。

待办到点时，悬浮小狗旁显示可直接勾选的待办。使用应用首页时也由悬浮小狗显示。待办到达时会收起已打开的互动菜单。同一次投递只入队一次，勾选使用事项 ID、发生时间和令牌保存完成记录。重复事项保留后续提醒。隐藏、锁屏或关闭桌宠时，系统通知与投递记录按既有设置处理。

## 动作与设备验收

审片后保留了原计划 59 项中的 56 项。日常移动为走路和慢跑。追球左右两向及玩球的帧、节奏和位移有独立回归检查。最终资源包含 81 个普通、方向及连接片段，另有 49 条相位退出桥。[动作清单与制作方法](../art/live2d/review2/integration/README.md)

## 0.2.1-preview.4 设备验收

本版与 preview.3 共用包名 `com.cutedog.app.motionpreview` 和签名，版本号为 6。语音听写及回答写到应用的共享聊天记录，桌面小窗与「陪伴」页可以查看。旧记录会在已有数据库上迁移。原始录音只在内存中处理。

普通话听写与固定 A 声线均随 APK 安装。Android 8 的 64 位模拟器在断网状态下直接从 APK 读取模型，合成了两句不同的中文。独立识别器完整转写了第二句「我把小球叼过来了，你还想再玩一次吗？」。提速前的对照版本在 4 核、5 GiB 内存的 x86_64 模拟器上，第一次生成完整短句用时 17.4 秒，第二句用时 22.6 秒。新版保留相同的声音参考，采用分段生成、提前载入和 CPU 专用指令，录音时就开始听写。手机上的速度取决于 CPU、当时的负载和可用内存。[包内语音与裁剪验证](offline-pet-speech.md)
