# 动作预览 0.2.1-preview.2

## 点击小狗与待办

首页和桌面悬浮窗共用同一个原生待办勾选行。单击、双击和短距离抚摸按手势设置触发小狗的动作，旧版本保存的单击聊天或菜单选项会回落到摸摸。明显的连续抚动更新小狗的注意方向，长按后拖动仍用于移动悬浮窗。

真实闹钟与错过提醒恢复队列可以向可见的小狗提交待办。首页在前台时优先由首页小狗显示，同一事项的同一次投递只排队一次。勾选使用对应投递的事项 ID、发生时间和令牌，经过与系统通知相同的接收器保存。重复事项保留后续提醒。隐藏、锁屏或没有可见桌宠时，系统通知与投递记录按既有设置处理。聊天、每日短句、事项详情、显示或隐藏等功能仍可从各自页面或系统通知进入。

## 动作与设备验收

审片后保留了原计划 59 项中的 56 项。日常移动为走路和慢跑。追球左右两向及玩球的帧、节奏和位移有独立回归检查。最终资源包含 81 个普通、方向及连接片段，另有 49 条相位退出桥。[动作清单与制作方法](../art/live2d/review2/integration/README.md)

同一调试签名 APK 已在 Android 8.0 和 15 模拟器上覆盖安装。两台设备都保留了升级前从界面创建的待办。Android 8.0 实测搜索键收起键盘、普通点击与待办勾选、Launcher 上的悬浮狗到点勾选。APK 内 4,204 份角色资源与审片输入逐字节相同。

模拟器的短时播放结果不覆盖实体手机的长期温升、耗电、厂商后台回收和实际触控体验。仍需实机评估的场景还包括系统时钟与重复提醒组合、长期联网会话及无障碍操作。[原始需求](原始需求.md)
