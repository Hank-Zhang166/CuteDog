# 桌宠互动与动作预览

## 点击小狗与待办

在「小狗」页开启悬浮窗权限并召唤桌宠。轻点头部，小萨会享受摸头、蹭一蹭或歪头。点腿或爪子，它会抬爪、舔爪或伸展。点尾巴会摇尾。点躯干使用「互动手势」里的设置。命中区域跟随每一帧的姿势和朝向，避开透明处和嘴边的球、零食与勺子。

在小狗身上同一位置双击，在它旁边打开互动面板。可以连续选投球、喂食、摸摸、呼唤或休息等，点面板外收起。点「聊聊天」打开聊天小窗，点「收起聊天」回到互动面板。保持按住后再移动即可拖动桌宠。锁定位置时仍可轻抚、双击和使用菜单。屏幕阅读器通过「打开互动菜单」操作进入。

preview.6 的互动面板由桌宠服务直接以按钮区域的大小加到悬浮层。双击时底下的桌面或应用仍在前台，面板外的点击由 Android 递送给下方窗口，同时收起面板。

在菜单或聊天窗口按住麦克风说话，松手后小狗开始回答，滑出按钮会停止这轮录音。首次使用时在 App 的「豆包实时语音」设置填写语音 API Key 和豆包搜索 Custom API Key，并确认录音实时发送给豆包。语音和搜索密钥由 Android Keystore 加密保存。问答文字保存在桌面小窗和「陪伴」页共用的聊天记录里。直接键入文字仍使用「模型设置」中的文字服务。点菜单外收起面板时会停止正在进行的语音轮次。[豆包实时语音协议](https://docs.volcengine.com/docs/doubao-voice/end-to-end-real-time-voice-full-duplex-version?lang=zh)

待办到点时，悬浮小狗旁显示可直接勾选的待办。使用应用首页时也由悬浮小狗显示。待办到达时会收起已打开的互动菜单。同一次投递只入队一次，勾选使用事项 ID、发生时间和令牌保存完成记录。重复事项保留后续提醒。隐藏、锁屏或关闭桌宠时，系统通知与投递记录按既有设置处理。

## 动作与设备验收

审片后保留了原计划 59 项中的 56 项。日常移动为走路和慢跑。追球左右两向及玩球的帧、节奏和位移有独立回归检查。最终资源包含 81 个普通、方向及连接片段，另有 49 条相位退出桥。[动作清单与制作方法](../art/live2d/review2/integration/README.md)

## 0.2.1-preview.4 设备验收

本版与 preview.3 共用包名 `com.cutedog.app.motionpreview` 和签名，版本号为 6。语音听写及回答写到应用的共享聊天记录，桌面小窗与「陪伴」页可以查看。旧记录会在已有数据库上迁移。原始录音只在内存中处理。

Android 8 使用 4 核、5 GiB 内存的 x86_64 模拟器。终版安装在独立数据盘上，从 preview.3 覆盖升级，在飞行模式下首次运行固定 A 声线。下表比较相同设备配置和文本，从请求合成计到整句波形生成完毕。

| 朗读内容 | 提速前 | 新版 |
| --- | ---: | ---: |
| 我喜欢小狗。（进程首次合成） | 17.43 秒 | 9.32 秒 |
| 我把小球叼过来了，你还想再玩一次吗？（接着合成） | 22.64 秒 | 6.39 秒 |

新版第二句的音频时长为 3.14 秒。独立普通话识别器完整识别第一句，第二句将「叼」写成「调」，其余文字一致。[包内语音与裁剪验证](offline-pet-speech.md)

Android 8 从公开的 preview.3 直接升级到最终签名包，原 UID、待办及其全部 13 个核对字段均保留。Android 15 先用同签名的本版候选验证了相同的 13 个字段，再覆盖安装最终包。在 Android 15 的断网完整回归中合成上表两句，分别用时 5.19 秒和 6.60 秒。第二句的音频为 2.73 秒，独立普通话识别器逐字识别了两句话。新引擎启动后清除了旧版的 114.20 MB 语音模型缓存，应用私有目录中没有第二份 GGUF 权重。

在这台 Android 8 模拟器上输入固定的 2.35 秒普通话录音，经本地 HTTPS 重放此前一条真实的 DeepSeek 回复（含标点共 35 个字符）。每轮重新合成并播放全部内容。由松开麦克风到系统混音器开始消费声音，终版首次对话为 **21.71 秒**，连续对话为 **12.99 秒**。其中首次准备普通话识别并保存听写用时 8.83 秒，连续对话用时 0.08 秒。提速前同一流程分别为 140.96 秒、90.66 秒，旧版冷启动测试期间主机也在编译。终版分别在松手后 27.71 秒、19.08 秒播完，两轮均无音轨欠载。

在 Android 15 上还测试了日常回复「好呀，我把小球叼来啦。」。使用同一段录音、同一条本地 HTTPS 文本流，每轮都重新听写并生成音频。由松开麦克风计到系统混音器开始消费声音，提速前两轮为 42.22 秒、38.86 秒，新版为 **7.34 秒、5.73 秒**。新版分别在松手后 9.13 秒、7.35 秒播完。系统游标为间隔约 0.3 秒的采样观察，实体手机与公网服务时延另计。

两台本地测试设备均核对了已安装 APK 的 SHA-256 `7c35e389646da1779be330b97af374dfd31107ea7c65129a4fc088f03232f4a4`。专门的音轨测试先让播放器耗尽缓冲，再只写入 128 帧，确认系统游标越过最后一帧。窗口测试在桌面小窗、应用「陪伴」页和重新打开的小窗中，逐次匹配了用户听写与小狗回答的正文和可见屏幕坐标。

GitHub 独立构建通过了 217 项 JVM 测试及 Android Lint。Android 8、Android 15 授权阶段各实际通过 62 项，另各有 3 项留给拒绝权限阶段。拒权阶段的 3 项在 Android 15 全部通过，Android 8 因系统版本均跳过。[完整双平台验证记录](https://github.com/Hank-Zhang166/CuteDog/actions/runs/45824228389)
