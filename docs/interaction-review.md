# 桌宠互动与动作预览

## 点击小狗与待办

在「小狗」页开启悬浮窗权限并召唤桌宠。首页保留桌宠设置入口。轻点或轻抚悬浮小狗会得到动作回应；在同一位置双击打开互动菜单，可以选投球、喂食、摸摸、呼唤或休息等，也可点「聊聊天」在桌面上打开聊天小窗，点「收起聊天」回到原先的界面。保持按住后再移动即可拖动桌宠。锁定位置时仍可轻抚、双击和使用菜单。屏幕阅读器通过「打开互动菜单」操作进入。

在菜单中按住麦克风说话，松手发送，录制中把手指移出按钮会取消。首次使用时由 Android 询问麦克风权限，允许后需重新按住。点菜单外可以收起菜单，正在进行的语音轮次会停止。

待办到点时，悬浮小狗旁显示可直接勾选的待办。使用应用首页时也由悬浮小狗显示。待办到达时会收起已打开的互动菜单。同一次投递只入队一次，勾选使用事项 ID、发生时间和令牌保存完成记录。重复事项保留后续提醒。隐藏、锁屏或关闭桌宠时，系统通知与投递记录按既有设置处理。

## 动作与设备验收

审片后保留了原计划 59 项中的 56 项。日常移动为走路和慢跑。追球左右两向及玩球的帧、节奏和位移有独立回归检查。最终资源包含 81 个普通、方向及连接片段，另有 49 条相位退出桥。[动作清单与制作方法](../art/live2d/review2/integration/README.md)

## 历史版本 0.2.1-preview.2 设备记录

交付 APK 的 SHA-256 为 `6bc5456ce59ae594774392bda27b57a913cbd35465153e9c82d3f8a54735d443`，大小为 575,761,326 字节。204 项 JVM 测试通过。Android 8.0 的 45 项适用设备测试通过，另外 3 项针对较新版本的权限；Android 15 按授权与拒权状态共通过 48 项。两台模拟器都使用安装包内的播放器逐帧处理挠耳、打哈欠、整理毛发和玩球四段，共 418 帧。
